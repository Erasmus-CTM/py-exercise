py-exercise – Feature Overview

One example per feature of the interactive Python exercise extension

This document walks through every feature of the py-exercise extension. Write your solution in the editor and press Check (or Shift+Enter) to run the hidden unit tests.

1 – Basic exercise

The simplest exercise: a label to identify it, starter code, and hidden assert statements below ## TESTS ##. Each assertion is one test and is reported individually.

Task: Write a function add(a, b) that returns the sum of two numbers.

2 – Caption

Use #| caption: to show a short title above the editor. Useful when you embed exercises inside a longer document and want to label them clearly.

3 – Capturing print() output

print() calls in the student’s code are captured and shown below the editor, independently of the test results.

Task: Write a function greet(name) that prints "Hello, <name>!" and also returns that string.

4 – Forbidden imports (per-cell)

#| forbidden-imports: blocks specific module names (both import x and from x import … forms). The check runs on the AST — the code is never executed if a violation is found.

The global front matter of this document already forbids os, sys, and subprocess for every exercise. The cell below additionally forbids math.

Task: Write a function circle_area(r) that returns the area of a circle with radius r. Use 3.14159 instead of math.pi.

5 – Forbidden keywords (per-cell)

#| forbidden-keywords: blocks built-in functions, method names, or language keywords (for, while, lambda, class, with, try, raise, …).

Task: Write a function my_sum(lst) that returns the sum of all elements in a list. The built-in sum() is not allowed.

Task: Write a recursive function factorial(n). Loops (for, while) are not allowed — the solution must be recursive.

6 – Hidden test hints (show-test-hints: false)

By default, the assertion message is shown when a test fails. Setting #| show-test-hints: false hides those messages so students cannot infer what is being tested.

Task: Write a function is_palindrome(s) that returns True if the string is a palindrome (ignoring case), False otherwise.

7 – Submission export

The submission header above and the Export results button below are enabled by setting submission: true in the document front matter. Students enter their Student ID and Quiz ID, then click the button to get an encoded string to submit.

The encoded string can be decoded by the instructor with:

import json, base64

def decode_submission(encoded: str, key: str = "py-exercise") -> dict:
    key_bytes = key.encode("utf-8")
    xored     = base64.b64decode(encoded)
    raw       = bytes(b ^ key_bytes[i % len(key_bytes)] for i, b in enumerate(xored))
    return json.loads(raw.decode("utf-8"))

data = decode_submission("...", key="demo-key-2026")
print(data["sid"], data["results"])

8 – JSON download

The Download as JSON button (in the footer below) saves the current editor content and test results of every exercise to a local file — for personal documentation. No server is involved.

The download is always available, regardless of whether submission mode is enabled.
